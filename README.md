# Профілювання та оптимізація програми (множення матриць)

Лабораторна з системного програмування. Програма: множення матриць N×N типу double (C).
Середовище: MacBook M3. Linux-частина (time, perf, FlameGraph) в Ubuntu 26.04 ARM64 (UTM/QEMU), енергія на macOS (powermetrics).

## Версії програми
- **A**: `gcc -O0`, порядок циклів i,j,k
- **B**: `gcc -O3`, порядок циклів i,j,k
- **C**: `gcc -O3`, порядок циклів i,k,j (зміна коду)

## 1. FlameGraph
Побудова: `scripts/flame.sh` (perf record -e cpu-clock -F 999 -g → perf script → stackcollapse-perf.pl → flamegraph.pl).
Результати: `vm-results/flame_matmul_O0.svg`, `flame_matmul_O3.svg`, `flame_matmul_O3_ikj.svg`.
Ширина блоку це частка часу CPU, висота це глибина стеку. Гаряча функція `multiply` (≈99% часу).

## 3. Енергоспоживання (macOS, N=1500)
Метод: `sudo powermetrics --samplers cpu_power,tasks --show-process-energy -i 1000`.
- Idle (baseline): 0,211 Вт (перший замір 1,5 Вт відкинуто через фонові процеси).
- 3.1 Енергія системи = сума замірів Combined Power (крок 1 с).
- 3.2 Енергія програми = (P_система − P_idle) × t; додатково Energy Impact по процесу.

## 4. Порівняння до і після оптимізації
| Версія | Час | P системи | E системи | E програми |
|---|---|---|---|---|
| A | 22 с | 1,147 Вт | 25,23 Дж | ≈20,6 Дж |
| B | 7 с | 1,454 Вт | 10,18 Дж | ≈8,7 Дж |
| C | ≈0,9 с | 2,409 Вт | ≈2,17 Дж | ≈1,98 Дж |

### 4.1 Асемблер
- `-O0`: змінні на стеку (`[rbp-12]`, `ldr/str [sp,#..]`), скалярні `mulsd/addsd`, адреса рахується заново.
- `-O3`: змінні в регістрах.
### 4.1.1 SIMD
- x86-64 `-O3 -mavx2 -mfma`: `vfmadd213pd ymm0, ymm1, [..]`, 4 double за інструкцію (256 біт).
- ARM64 `-O3`: `fmla v0.2d, v1.2d, v31.d[0]`, 2 double за інструкцію (128 біт, NEON).
- Векторизація можлива лише в порядку i,k,j, бо `b[k*N+j]` і `c[i*N+j]` лежать підряд.
### 4.2 Час та показники
Таблиця в розділі 2. Прискорення: B 3,1×, C ≈21×.
### 4.3 FlameGraph після оптимізації
Зразків у `multiply`: A 6,79 млрд, B 2,27 млрд, C 0,31 млрд. Форма графіка однакова (нормування на 100%), змінилась абсолютна ширина. Частка `multiply` у C 95,9% (закон Амдала).
### 4.4 Енергія
Потужність зростає (1,15 → 1,45 → 2,41 Вт), але час падає сильніше, тому енергія менша приблизно в 11–12 разів (принцип race to idle).
